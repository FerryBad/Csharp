Final Project

Combine variables, input, a loop, and if/else into a number guessing game.

🌱 Beginner friendly📖 Learn🧩 Practice
12

Build a guessing game

Follow the steps, study the example, then complete the small challenge.

🐻 C# Buddy says:
Read one step at a time. You do not need to memorize everything.

1. Learn the idea

1Set a secret number such as 7.
2Ask the player for a guess with Console.ReadLine.
3Keep asking while the guess is not correct.
4Use if/else to say too low, too high, or correct.

2. Worked example

Here is a finished example.

int secret = 7;
int guess = 0;
while (guess != secret)
{
    Console.Write("Guess: ");
    guess = int.Parse(Console.ReadLine() ?? "0");
    if (guess < secret) Console.WriteLine("Too low!");
    else if (guess > secret) Console.WriteLine("Too high!");
    else Console.WriteLine("Correct!");
}

3. Your challenge

  • Ask the player for a guess with Console.ReadLine.
  • Keep asking while the guess is not correct.
  • Use if/else to say too low, too high, or correct.
